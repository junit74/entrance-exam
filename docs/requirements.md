# 2027학년도 논술전형 경쟁률 대시보드

요구사항 인터뷰 및 1차 출처 조사 정리: 2026-09-09

## 목적과 확정 범위

자녀의 논술 지원 대학·모집단위를 경쟁률과 과거 입시결과를 비교하여 선택하는 개인용 대시보드다.

- 대상은 경기대학교, 수원대학교, 한국기술교육대학교, 한국공학대학교, 가천대학교, 삼육대학교의 **6개 대학**이다.
- 2027학년도 논술전형에 해당하는 실제 모집단위만 표시한다.
- 자연과학계열은 제외하고 공학계열을 우선 표시한다. 그 외 계열을 일괄 제외하지 않는다.
- 현재 모집인원, 지원인원, 경쟁률, 학교별 자료 기준 일시를 표시한다.
- 학교별 원문 기준 일시가 저장된 자료보다 최신일 때 경쟁률을 반영한다.
- 경쟁률을 그래프로도 제공하고, 학교 상세에서 모집단위별 과거 여러 학년도의 경쟁률을 비교한다.
- 모집단위별 추가합격 관련 정보는 공식 자료에서 확보되는 범위에서 제공한다.
- 수능최저학력기준은 표시한다. **성적 입력과 충족 여부 판정은 구현 범위에서 제외한다.**
- 로컬 서버를 사용한다. 대시보드 브라우저를 닫아도 서버가 실행되는 동안 자동 수집하고 이력을 보존한다.

## 구현 기본안

아래 항목은 사용자가 별도로 지정하지 않은 부분에 대한 기본안이다.

- 로컬 서버와 JSON 파일로 수집 작업 및 저장을 관리한다. GitHub Actions와 Pages에서도 같은 형식을 사용하며 별도의 DB 서버는 필요하지 않다.
- 로컬 서버는 로컬 주소에 바인딩한다. GitHub에서는 Actions가 수집하고 Pages가 정적 화면을 제공한다.
- 과거 비교 범위는 우선 2024~2026학년도 3개년으로 한다. 자료가 없는 연도는 추정해서 채우지 않는다.
- 첫 화면은 6개 대학의 모집단위를 함께 비교하는 표가 중심이며, 공학을 우선하고 계열 내에서는 현재 경쟁률 오름차순을 기본으로 한다.
- 학교, 모집단위 검색 및 정렬을 제공하고, 학교 요약에서 학교 상세로 이동한다.
- 학교 요약 경쟁률은 해당 논술 모집단위의 지원인원 합계 / 모집인원 합계로 계산한다. 학과별 경쟁률의 단순 평균을 사용하지 않는다.
- 자연과학 제외 등 화면 필터가 집계에 적용되면 집계 대상도 표시한다. 학교 논술 전체 집계와 필터 적용 집계를 혼동하지 않게 한다.
- 그래프는 현재 모집단위 경쟁률 비교, 수집 시작 이후 시간별 변화, 과거 학년도별 최종 경쟁률 비교를 제공한다.

## 수집 및 갱신 규칙

1. 서버 시작 시 각 학교를 확인하고 이후 공지상 주기에 맞춰 10분마다 확인한다. 수집은 페이지 접속 여부에 의존하지 않는다.
2. 학교, 학년도, 전형, 모집단위를 식별하고 원문에 표시된 일시를 읽는다. HTTP 응답 시각이나 조회 시각을 자료 기준 시각으로 대체하지 않는다.
3. 학교별 `자료 기준 일시`, `마지막 확인 시각`, `마지막 수집 시도 및 성공 여부`를 구분하여 저장한다.
4. 저장된 자료보다 기준 일시가 최신인 경우 검증된 학교별 스냅샷을 추가한다. 기준 일시가 같거나 오래된 응답으로 현재 수치를 덮어쓰지 않는다.
5. 기준 일시가 최신이면 지원인원이 이전과 같아도 최신 현황으로 저장한다. 지원인원이 감소한 경우도 원문 정정 가능성이 있으므로 감소만으로 거부하지 않는다.
6. 한 학교의 모집단위 데이터를 검증하고 한 번에 반영하여 서로 다른 발표 시점의 학과 수치가 섞이지 않도록 한다.
7. 재시도 및 서버 재시작으로 동일 스냅샷이 중복 저장되지 않도록 한다. 한 학교의 실패가 다른 학교의 갱신을 막지 않게 한다.
8. 연결 실패, 파싱 실패, 학년도 불일치, 논술 표 누락 시 기존 정상 자료를 보존하고 확인 실패를 표시한다. 실패를 지원자 0명이나 모집 종료로 바꾸지 않는다.
9. 마감일 공개 종료 후에는 중간 자료를 유지하고 `최종 발표 대기`로 표시한다. 원문을 다시 확인하여 최종 현황을 수집한다.
10. `최종` 여부는 공식 원문의 명시적 상태로 확인한다. 날짜가 사라지고 최종 마감 문구만 남는 변경은 검토 후보를 저장하고 기존 현황을 유지한다. 신뢰할 수 있는 발표 일시가 없으면 임의의 최신 시각을 만들어 덮어쓰지 않는다.
11. 동일한 기준 일시인데 본문이 달라지는 경우는 별도 변경 감지로 기록하고 기존 자료를 자동 덮어쓰지 않는다. 후보는 data/review에 보존하고 검토 필요를 표시한다.

로컬 컴퓨터가 꺼지거나 잠들거나 서버가 종료된 동안에는 수집할 수 없다. 재시작 후 최신 현황을 가져오되, 공식 과거 시점 자료를 별도로 확보하지 못한 구간은 그래프에 공백으로 남긴다. 수집 시작 이전 이력을 만들어내지 않는다.

## 모집단위와 과거 자료의 해석

- 대학의 논술전형 표에 실제로 있는 모집단위를 기준으로 한다. 다른 전형에서 같은 이름의 학과가 등장한다는 이유로 포함하지 않는다.
- 화학과와 화학공학과처럼 자연과학과 공학을 구분한다. 대학의 공식 학과·모집단위 설명으로 분류하며 단어 포함 여부만으로 결정하지 않는다.
- 자유전공·자율전공·융합 모집단위는 실제 선택 가능한 전공을 확인한다. 혼합 계열이나 분류 미확정 모집단위는 그 상태를 드러내며 순수 공학으로 단정하지 않는다.
- 한국공학대의 2027 논술은 자유전공학부 및 자율전공 단위로 공지되어 있다. 이를 임의의 개별 학과 경쟁률로 분할하지 않는다.
- 같은 모집단위 이름이라도 전형, 캠퍼스, 연도에 따라 별도로 식별한다.
- 개편·통합·분리·신설은 공식 근거가 있는 경우에만 이전 모집단위와 연결한다. 비교할 수 없는 연도를 하나의 연속 그래프로 연결하지 않는다.
- 과거 학년도 값은 최종 경쟁률임을 명시한다. 2027 접수 중 경쟁률과 과거 최종 경쟁률을 같은 진행 시점의 값으로 취급하지 않는다.
- 충원합격 인원, 최종 예비번호, 충원율은 다른 항목이다. 원문의 항목명과 정의를 보존하며 서로 변환하여 채우지 않는다.
- 값이 없으면 `미공개`, 아직 조사하지 못했으면 `확인 중`, 전형이 없으면 `해당 없음`으로 구분한다. 누락값을 0으로 표현하지 않는다.

## 화면 구성 기본안

- 전체 비교: 학교, 실제 모집단위, 계열, 모집인원, 지원인원, 현재 경쟁률, 직전 저장 현황 대비 지원자 증감, 자료 기준 일시, 수집 상태.
- 학교 상세: 논술 모집단위별 현재 현황, 수능최저 조건, 과거 3개년 모집인원·지원인원·최종 경쟁률·공개된 충원 정보, 출처 링크.
- 그래프: 현재 경쟁률 비교, 선택 모집단위의 수집된 시간별 경쟁률, 비교 가능한 과거 학년도별 최종 경쟁률.
- 정보가 최신인지 판단할 수 있도록 원문 기준 일시와 마지막 확인 시각을 표시한다. 학교별 발표 시각이 다르면 이를 숨기지 않는다.

## 구현 완료 검증 기준

- 실제 원문과 6개 대학의 논술 모집인원·지원인원·경쟁률이 일치한다.
- 논술에 없는 모집단위가 섞이지 않고 자연과학 제외·공학 우선 분류에 근거가 있다.
- 최신 자료 반영, 동일·과거 자료 무시, 실패 시 기존 자료 보존, 학교별 원자적 저장이 동작한다.
- 브라우저를 닫은 상태에서도 서버가 계속 수집하며 재시작 후 이력이 유지된다.
- 공개 종료와 수집 오류를 구분하고, 공식 최종 현황을 중간 현황과 구분한다.
- 과거 최종 경쟁률, 충원 인원, 예비번호와 미공개 상태가 출처에 맞게 표시된다.
- 수능최저는 조건만 표시하며 성적 입력 또는 자동 판정 UI가 없다.
- 그래프와 요약 집계가 표와 일치하며 미수집 구간이나 비교 불가능한 모집단위를 오해하게 연결하지 않는다.
