# 2027 논술 출제 정보 독립 재검증

검증일: 2026-09-09. 대상 구현: `a45e44a`.

## 검증 범위와 방법

세 서브 에이전트가 13개 대학을 4·4·5개로 나누어 공식 2027 모집요강·논술가이드를 새로 내려받고 표와 각주를 이미지로 직접 판독했다. 기존 JSON이나 테스트 통과를 정답의 근거로 삼지 않고, 논술 유형·출제 과목·미적분/기하/확률과 통계 포함 여부·시험시간·문항 구성·모집단위 연결을 원문과 대조했다.

주 에이전트는 실제 GitHub Pages에 배포된 카탈로그와 로컬 카탈로그의 일치를 확인했다. 현행 242개 모집단위 전체의 단일 그룹 연결을 검사하고, 자연과학을 제외하여 화면에 표시되는 222개 모집단위의 상세창에서 유형·과목·선택과목 태그·문항 구성·시간이 저장값과 일치하는지 확인했다. PC용 표와 모바일용 카드의 상세 버튼 444개를 검사했으며, 모바일 390px에서는 모집단위별 222개 상세창의 왼쪽 정렬과 가로 넘침도 검사했다.

## 결과와 반영 사항

출제 범위·시험시간·문항 구성·모집단위 연결의 내용상 불일치는 발견하지 못했다. 출처 표시와 접근성 2건을 보완했다.

1. 한국항공대 출처 라벨의 인쇄 쪽수를 40쪽에서 39쪽으로 수정했다. PDF 41번째 페이지로 연결되는 URL은 이미 올바르다.
2. 한신대 학과별 계열 근거 링크를 21쪽 일정표에서 20쪽의 계열 명시 모집단위 표로 옮겼다. 적용한 계열·문항 구성에는 변화가 없다.

## 실제 표시 검증

- `npm run check`: 구문 검사, 테스트 30개, 정적 사이트 빌드 통과.
- 242개 모집단위: 누락·중복 연결 0건.
- 표시 대상 222개 모집단위: 상세 내용과 카탈로그 사이의 불일치 0건.
- 모바일 390px: 출제 정보의 왼쪽 정렬 불일치 및 상세창 가로 넘침 0건.
- 대학 화면은 해당 대학의 모든 논술 유형을 설명하고, 학과 상세는 선택 학과에 연결된 한 유형만 표시한다.
- 선택과목 ‘미적분’ 제외와 수학Ⅱ의 미분·적분 내용 제외를 혼동하지 않도록 상세창에도 안내가 남아 있다.

## 범위의 한계

이번 검증은 새로 추가한 논술 출제 정보와 그 표시를 대상으로 한다. 실시간 경쟁률, 과거 입시결과, 수능최저 등 다른 기능 전체를 공식 자료와 다시 대조했다는 뜻은 아니다. 출제 정보는 공식 자료 확인일 기준이며, 경쟁률의 10분 자동 수집으로 모집요강 정정까지 자동 반영되지는 않는다.
