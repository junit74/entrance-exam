## 검증과 유지 관리

실제 HTML 6개를 테스트 입력으로 보존했습니다. 전형 식별, 셀 병합, 학교명과 학년도, 모집단위별 경쟁률, 전체 합계, 최신 일시 비교, 오류 시 보존을 테스트합니다. 과거 결과도 지원/모집 인원과 경쟁률 및 연도별 합계를 검증합니다. 한국공학대 과거 경쟁률은 소수 첫째 자리까지 공지된 값을 보존합니다.

과거 결과와 수능최저·분류는 수동 검증한 자료입니다. 입학처의 정정 공지가 생기면 JSON과 출처를 함께 수정해야 합니다. 현재 경쟁률만 자동 수집합니다. 실제 GitHub Pages 배포와 모바일 접속을 확인했습니다. GitHub 실행 환경에서는 진학어플라이가 보안 확인(403)을 반환하여 현재 운영은 로컬 수집 결과를 GitHub에 자동 게시하는 방식입니다.

2026-09-09 학교별 독립 재검증 결과와 수정 내역은 [감사 보고서](audit-2026-09-09.md)에 정리했습니다. 가천대의 공식 최종접수 표와 입시결과 엑셀 간 경쟁률 차이 3건을 기록했으며, 자연과학 제외 후 표시 대상인 2건은 화면에 두 수치와 출처를 함께 표시합니다.

### 모집단위별 문항 구성

2026-09-09에 공통 출제 과목을 쓰는 약술형 논술도 모집단위별 계열로 세분화했습니다. 대학 요약과 학과 상세 모두 각 유형의 문항 구성만 표시합니다.

- 강남대: 모집요강 13쪽 모집단위 표와 52쪽 논술고사 표. 부동산건설학부는 공학계(국어 3·수학 7), 자유전공학부는 별도 구성(국어 5·수학 5).
- 수원대: 16~17쪽 계열 표, 28쪽 논술 가이드. 아동가족복지학과·의류학과·도시부동산학과는 자연계열(국어 5·수학 10), 디지털콘텐츠는 인문계열 평가방법(국어 10·수학 5).
- 가천대: 32~33쪽 계열 표, 39쪽 문항 구성. 금융·빅데이터학부는 자연계열(국어 5·수학 8), 응용통계학과는 인문계열(국어 8·수학 5). 같은 날짜에 고사를 치르는 학과라도 계열을 날짜로 추정하지 않음.
- 삼육대: 논술가이드 10쪽 계열 표, 13쪽 문항 구성. 창의융합자유전공학부는 인문, 미래융합자유전공학부는 자연.
- 한신대: 모집요강 20쪽 계열 표와 21쪽 논술 평가방법. 자유전공학부는 인문, 금융공학·빅데이터융합학·AI·SW학·AI시스템반도체학은 자연.
