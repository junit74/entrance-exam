# 홍익대학교 세종캠퍼스 과거 논술자료 독립 감사

- 감사일: 2026-09-11
- 대상: 추가 구현 커밋 `98a465e`의 `data/historical.json`, `data/catalog.json`
- 수행: 구현 담당과 별도 sub-agent
- 결과: **2024~2026학년도 30행의 모집인원·지원인원·경쟁률 90개 값과 추가합격률 30개 값 모두 원문과 일치. 수정 필요 사항 없음.**

## 확인 방법과 원문

[대학 공식 경쟁률 목록](https://www.hongik.ac.kr/kr/admission/competition-rate.do)에서 각 링크가 해당 연도 세종캠퍼스로 연결되는 것을 확인했다. 세 링크의 HTML을 새로 내려받아 서비스명이 `수시모집(세종캠퍼스)`인지 확인하고, 기존 앱 파서를 사용하지 않는 별도 Cheerio 추출로 `논술전형` 표의 모든 10행을 저장 자료와 비교했다. 모집·지원·경쟁률은 아래 공식 PDF 표 전체와도 시각적으로 대조했다.

각 추가합격률은 PDF 전체 페이지에서 열 제목과 수치를 읽은 후 별도 기대값 목록으로 대조했다. 2026년 표는 경쟁률 다음에 **실질경쟁률**, 그 다음에 **추가합격률**이 있다. 저장된 111.11%(나노반도체공학과), 142.86%(조선해양모빌리티공학과) 등은 추가합격률 열의 값이며 실질경쟁률과 혼동되지 않았다. 추가합격률 정의는 추가합격인원 ÷ 모집인원 × 100이다. 모든 행의 `additionalAdmissions`와 `reserveRank`가 null이고, `admissionText`가 공식 비율을 퍼센트로 표시함을 확인했다. 비율을 실제 인원이나 마지막 예비번호로 추정하지 않았다.

## 학과명 변경과 신규 인문 모집단위

[2026 모집요강 PDF 72쪽, 인쇄 70쪽](https://www.hongik.ac.kr/kr/admission/recruitment.do?articleNo=137200&attachNo=82961&mode=download#page=72)의 세종캠퍼스 학과 명칭 변경 표 전체를 확인했다. 다음 5개 연결은 모두 일치하며 2024·2025년 원문에 각각 이전 이름이 존재한다.

| 2024·2025 자료명 | 2026 이후 자료명 |
|---|---|
| 과학기술대학자율전공 | AID융합과학기술대학자율전공 |
| 나노신소재학과 | 나노반도체공학과 |
| 기계정보공학과 | AI기계융합공학과 |
| 조선해양공학과 | 조선해양모빌리티공학과 |
| 바이오화학공학과 | 바이오화학융합공학과 |

기존 10개 모집단위는 앱과 같은 이름·캠퍼스 매칭 조건으로 각 연도에 정확히 한 행씩 연결된다. 이전 이름은 표시 자료에서 보존된다.

[2027 모집요강 PDF 72쪽, 인쇄 70쪽](https://www.hongik.ac.kr/kr/admission/recruitment.do?mode=download&articleNo=152315&attachNo=91150#page=72)의 주요 변경사항 전체 페이지는 세종 인문계 논술 신설을 명시한다. 세종캠퍼스자율전공(인문·예능), 상경학부, 광고홍보학부의 과거 3개년 논술 표에는 대응 행이 없으며, 카탈로그에도 신설 안내가 있다. 각 모집단위의 과거 매칭 결과는 0건으로, 다른 전형이나 서울캠퍼스의 자료가 대신 연결되지 않는다.

## 범위

이 감사는 과거 입시결과 수치와 학과명 연결에 한정한다. 2027 현재 경쟁률·출제 범위·수능최저와 화면 동작은 별도 감사 범위다.
