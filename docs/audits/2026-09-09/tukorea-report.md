# 한국공학대학교 독립 감사

검증 대상: 배포 2026-09-09 12:38 KST JSON, 학교 원문 발표 12:30 KST. 공식 현재 페이지는 독립 ego-browser 공간 13에서 12:40 발표본을 직접 열었다. 과거자료는 대학 게시글 3개를 직접 열어 PDF 첨부 URL을 확인하고 제공된 공식 PDF의 2페이지 전체를 렌더하여 모든 행을 읽었다. parser.mjs 재실행 없이 숫자를 독립 전사해 대조했다.

## 결론

- 현재 논술 6행 전부 이름·모집인원 일치(총 200명). 5행 지원·경쟁률도 일치, 1행은 10분 후 정상 갱신이다. 같은 발표시각의 숫자 오류는 확인하지 못했다.
- 과거 2024 20행, 2025 27행, 2026 27행, 총 74행의 모집·지원·공식 발표 경쟁률·예비번호 296개 숫자 모두 일치. 이름·학부 병합 구조도 검토했다.
- 수능최저 없음 및 현재 공학4행/자유·융합1행/인문·사회(경영)1행 분류가 공식 요강과 부합한다.
- 숫자 오류와 별개로, 공식적으로 연결 가능한 현재 모집단위 2개의 과거 이름 연결이 배포 catalog에 없다. 아래 개선사항 참조.

공식 2027 요강: https://iphak.tukorea.ac.kr/bbs/filedown.php?bbsid=guide&file_seq=2027&save_file_nm=guide_20260907185426_2035.pdf (공식 fileview도 브라우저로 열었음)

21페이지 논술우수자 지원자격에 ‘수능 최저학력기준: 없음’ 명시. 17페이지 논술열에 31/26/33/25/15/70명, 총200명 직접 확인.
17페이지의 소속/선택 범위 기준 AI융합·IT반도체융합·스마트기계융합·첨단융합은 공학 전공들로 구성된다. 자유전공학부는 경영 등도 선택하므로 mixed가 적절하다. 경영 자율전공은 경영학·데이터사이언스경영·IT경영 중 선택하므로 humanities(사이트 인문·사회 분류)가 적절하다. 과거 공학/경영/자유전공 분류도 같은 기준에서 모순 없음. 학문분류는 대시보드의 수동 분류이며 공식 대학의 입시계열 문구를 그대로 인용한 것은 아니다.

## 숫자 오류와 별도: 근거 있는 과거 이름 연결 개선 2건

1. AI융합 자율전공(ID 3fed0b30989437ce): 현재 historicalNames 없음 → 2025/2026 각각 ‘SW 자율전공’ 연결 권고. 요강15페이지 ‘SW자율전공 → AI융합 자율전공’ 명칭변경 명시. 2025·2026 결과2페이지 SW 자율전공 20/195/9.8/9, 29/326/11.2/10으로 확인됨.
2. 경영학부 경영 자율전공(ID 6f05eb5ffcc81691): 현재 historicalNames 없음 → 2025/2026 각각 ‘경영 자율전공’ 연결 권고. 과거PDF2페이지 경영학부 병합셀에 속한 경영 자율전공이며 2027요강17페이지도 같은 구조. 2025·2026 수치 10/77/7.7/3, 13/117/9.0/1.

public/app.js lookupHistorical은 공백 제거 후 이름 일치 또는 historicalNames가 필요하므로 현재 구조에서는 이 2개 모집단위 상세에 2025/2026 비교자료가 연결되지 않는다. 의도적으로 보수적인 미연결 안내가 있으므로 공식 수치 오류가 아닌 개선사항으로 분리한다. 다른 4개 현재단위는 2025/2026 이름 직접 일치. 2024에는 현재 자율·자유전공 6개가 없어 임의 연결 금지가 타당하다.

- tukorea-evidence.json: 원문 숫자 독립 전사와 전행 비교(74행 전부 true).
- tukorea-live-1240.json: 공식 실시간 페이지 원문 text/tables.

- 같은시각 12:30 원본 HTML 재확인, 원문 PDF 바이트의 새 다운로드/해시 재대조는 수행하지 않았다. 게시글 첨부URL을 확인하고 기존 공식 PDF를 읽었다.
- 요청 범위 외 논술고사 성적/학생부 성적/타전형은 대조하지 않았다. 공유 코드·데이터·배포는 수정하지 않았다.
