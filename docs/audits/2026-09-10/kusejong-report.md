# 고려대학교 세종캠퍼스 독립 데이터 감사

검증일: 2026-09-10. 3개 서브 에이전트가 경쟁률·과거 연결, 논술·수능최저, 분류·지역을 나누어 공식 원문과 독립 대조했다. 주 에이전트는 실제 GitHub Pages의 학과 상세 표시를 확인했다.

## 논술 및 수능최저

공식 2027 모집요강 PDF 16~18쪽(인쇄14~16쪽), PDF20쪽(지역인재)을 새로 내려받아 전체 페이지 이미지의 표·병합 셀·각주를 확인했다. 29개 모집단위의 모집인원도 독립 전사하여 모두 일치했다.

- 자연Ⅰ 17개: 수학·수학Ⅰ·수학Ⅱ·미적분, 6문제 내외. 확률과 통계·기하 제외.
- 자연Ⅱ 약학과 1개: 위 과목 및 확률과 통계, 3문제 내외(소문항 있음). 기하 제외.
- 인문·체능 11개: 국어·사회·도덕(역사 포함) 통합형, 2문제 내외.
- 시험시간 전 모집단위 120분.
- 일반 25개: 국어·수학·영어·탐구 상위1과목 중 2개 영역 등급합6 이내.
- 자유전공 3개: 같은 영역 중 1개 영역3등급 이내.
- 약학과: 국어·수학(미적분/기하)·영어·과학탐구2과목평균 중 3개 영역 등급합5 이내.
- 모든 모집단위 국어·수학·영어·탐구2과목·한국사 필수응시 안내가 맞다. 약학을 제외하면 수학 선택 제한 없음, 탐구 사회/과학 혼합 허용.
- 약학의 논술 기하 제외와 수능 기하 선택 허용은 서로 다른 규정이며 현재 구분되어 있다.
- 첨단융합신약학과는 약학과와 달리 자연Ⅰ·일반2합6, 경제통계학부·국제스포츠학부는 인문형이다. 연결이 정확하다.

## 분류 및 과거 연결

자연과학4·공학11·인문사회8·보건의약2·자유융합3·기타1 = 29개. 자연과학 제외 시25개다. 위치는 세종 조치원이다. 표시 분야는 대학의 입시 자연계열 또는 등록금 계열과 동일한 개념이 아니다.

- 반도체물리·빅데이터사이언스는 공식 소개의 물리학·통계학 기반 및 등록금표의 이학 계열로 분류 근거를 교차 확인했다.
- 생명정보·식품생명·디지털헬스케어는 공식 공학 교육과정 및 등록금 공학 계열과 일치한다.
- 첨단융합신약은 약학대학 소속의 신약개발 연구 교육과정이다. 보건의약 표시는 교육 분야 판단이며 약학과와 같은 과정이라는 뜻이 아니다.
- 자유전공은 소속 단과대학 내 전공 선택이다. 과학기술은 자연·공학, 글로벌비즈니스 및 문화스포츠는 각각 해당 대학 내 전공을 선택한다.
- 컴퓨터융합소프트웨어 → 컴퓨터소프트웨어의 2026 명칭 변경과 자유전공 2026 신설은 공식 2025 입시결과 PDF 각주로 확인했다.
- 2024 현재 학과 연결23개, 2025 연결26개, 2026 연결29개로 다중 매칭이 없다.
- 반도체물리의 2024 옛 모집단위는 개편의 직접 비교 근거를 확인하지 않아 연결을 보류한 상태다. 원자료는 보존한다.
- 충원·예비는 확인된 경쟁률 원문에 없으며, 입시결과 PDF의 해당 열은 다른 전형에 속한다. 미확인 처리를 유지한다. 대학의 모든 자료에 미공개라고 단정하지 않는다.
- 시간별 이력은 도입 시점인 9월10일23:00부터이며, 도입 이전의 미수집 시간별 이력을 복원한 것은 아니다.

## 반영한 안내 보완 및 검증

1. 학교 공통/예외3곳 및29개 학과 최저에 제2외국어·한문으로 탐구 대체 불가 각주를 추가했다.
2. 약학의 학교/학과 논술 안내에 자연계 공통인 하위과목 간접 출제 가능 각주를 추가했다.
3. 자유전공3개에 선택 범위, 첨단융합신약에 별도 신약개발 연구 과정임을 설명했다. 관련 학과7개의 계열 근거 링크를 공식 학과 소개·규정으로 보완했다.
4. 각 담당 에이전트가 보완 문구를 재검토했다. 경쟁률 수치와 category 값은 변경하지 않았다.
5. GitHub Pages에서 표시되는25개 학과 상세의 출제그룹·과목·문항·최저 및 과거67개 연도별 행의 모집·지원·경쟁률을 실제 렌더링 결과와 대조하여 불일치가 없었다.
6. `npm run check`: 33개 테스트 및 정적 빌드 통과.
